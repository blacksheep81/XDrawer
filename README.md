# X 抽屉

**中文** · [English](README.en.md)

X 抽屉是一个 Chrome 扩展，把你在 X（Twitter）上的书签、喜欢和手动保存的帖子收进浏览器里的本地收藏库，方便搜索、分类和整理。

- 所有数据保存在当前浏览器的 IndexedDB 中，不经过任何服务器
- 原帖被删除或无法访问时，已保存的正文仍然可以阅读
- 不会修改你 X 账号里的帖子、书签或喜欢

## 功能

**导入与保存**
- **从 X 导入**：读取已登录账号的书签或喜欢。支持“X 网页同步”（推荐）和“滚动页面读取”（备用）两种方式，可以只扫新帖，也可以一直读到最后。遇到 X 的请求限制会自动等待后继续。
- **手动保存**：在 X 帖子页面点击右下角的「✦ 保存到 X 抽屉」。
- 支持多个 X 账号，侧栏可以按保存账号查看。

**搜索与筛选**
- 全文搜索正文、备注、作者、链接和标签，并支持以下语法：

  | 语法 | 含义 |
  |---|---|
  | `"design system"` | 精确短语 |
  | `-广告` | 排除关键词 |
  | `from:作者` / `-from:作者` | 指定或排除作者 |
  | `tag:标签` / `-tag:标签` | 指定或排除标签 |
  | `has:image` `has:video` `has:media` `has:link` `has:note` `has:tag` | 按内容筛选，前面加 `-` 表示排除 |
  | `is:read` `is:unread` `is:later` | 按阅读状态筛选 |

- 可以按类型、账号、作者、阅读状态、原帖状态和日期筛选，并把常用筛选保存为视图。
- 有卡片、列表、紧凑三种视图，可以合并多处保存的同一帖子。长帖子可以在卡片里「展开全文」。

**整理**
- 可以给帖子加标签（每条最多 20 个）、写备注、标记稍后读或已读，也支持批量整理。
- 侧栏的「整理」分组提供两个快捷入口：
  - **待整理**：还没有标签的帖子
  - **稍后读**：标记为稍后读的帖子
- **智能分类**：按关键词（任一或全部）、排除词、作者和附加条件（如 `has:image -has:link -from:someone`）自动归类，之后导入的帖子也会自动归入。
  - 可以设置自动添加的标签，也可以给已有帖子批量补标签，并且支持撤销。
  - 搜索框的条件可以直接保存为智能分类。读者自己会改动的条件（如 `tag:`、`is:`）不会被保存，对话框会提示。
- **人物·小号**：给别人的账号添加别名和备注，方便辨认。
- 可以检查原帖是否还能访问，也可以把所选帖子按链接、正文或 Markdown 列表格式分享。

**备份**
- 「备份与导出」菜单里有三项：
  - **导出 JSON 备份**：包含标签、备注和智能分类
  - **导出 CSV**：导出当前筛选结果
  - **导入备份**：已有的帖子会合并
- 支持浅色、深色和跟随系统三种主题。

## 安装

1. 下载或克隆本仓库：
   ```bash
   git clone https://github.com/blacksheep81/XDrawer.git
   ```
2. 在 Chrome 中打开 `chrome://extensions`，打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择仓库所在的文件夹。
4. 登录 [x.com](https://x.com)，点击工具栏上的 X 抽屉图标，再点「从 X 导入」。

扩展 ID 由 `manifest.json` 中的 `key` 固定为 `cfpjibdhkfnibjiigeiebdmmodmkclcd`，所以在不同电脑上加载时 ID 都一样。

## 隐私与权限

| 权限 | 用途 |
|---|---|
| `cookies` | 读取 x.com 的登录状态，用来以当前会话调用 X 网页接口。Cookie 和令牌不会写入收藏库。 |
| `tabs` | 打开收藏库页面，以及在后台标签页里检查原帖是否可以访问。 |
| `storage` | 已在清单中声明，当前代码没有用到。主题设置保存在页面的 localStorage 里。 |
| `x.com` / `twitter.com` | 在帖子页面显示保存按钮，以及读取书签和喜欢。 |

收藏数据只存在当前浏览器的这个扩展里。卸载扩展或清除扩展数据会删除收藏库，请定期用「导出 JSON 备份」保存一份。

## 文件结构

| 文件 | 作用 |
|---|---|
| `manifest.json` | 扩展配置（Manifest V3） |
| `background.js` | 后台脚本，处理手动保存 |
| `capture.js`、`status-path.js` | 注入 X 页面：保存按钮、滚动读取、原帖检查 |
| `xsync.js`、`x-web-features.json` | X 网页同步（只读） |
| `db.js` | IndexedDB 存储、智能分类和自动标签规则 |
| `library.html`、`library.js`、`style.css` | 收藏库主页面 |
| `people.js` | 人物·小号 |
| `popup.html`、`popup.js`、`popup.css` | 工具栏弹窗 |
| `theme.js`、`tokens.css` | 主题和设计变量 |

项目不需要构建，修改代码后在 `chrome://extensions` 点击扩展卡片上的刷新按钮即可。

## 注意

- X 网页同步依赖 X 网页端的内部接口。X 改版后可能暂时失效，这时可以先用「滚动页面读取」。
- 本项目与 X Corp. 无关。
